## 2. Comparison with 4570 at the same sites

- `vm_shared_region.c`: no gate, no selector; 4570's arm32 case (`:679-685`) uses `SHARED_REGION_BASE_ARM/SIZE_ARM/NESTING_*` = `0x1A000000/0x26000000/0x1A000000/0x26000000` (4570 `osfmk/mach/shared_region.h:66-69`), and no ARM-region `0x2C000000` exists in 4570 (only unrelated tables, e.g. `osfmk/corecrypto/ccaes/src/aes_tab.c:685`). All three arm32 geometries end at `0x40000000` (`0x1A000000+0x26000000`; `0x30000000+0x10000000`; gated `0x2C000000+0x14000000`) - the top is the invariant; the base moved with the OS era.
- `vm_map.c`/`vm_user.c`: 4570 implements the same semantics **unconditionally** - `if ((flags & VM_FLAGS_RETURN_DATA_ADDR) != 0) { offset_in_mapping = ...; size = vm_map_round_page(...); }` (`:15223-15228`) + `*address += offset_in_mapping` (`:15312-15314`); its `VM_FLAGS_USER_REMAP` already includes the flag (`vm_statistics.h:331-336`), value `0x100000` (`:308`). D13's gate = 4570 behavior behind the vmabi selector, plus overflow refusals 4570 lacks (`vm_map.c:11470-11477`).
- `vm_unix.c`: 4570's `check_np` (`:1358-1399`) has the same shape, and 4570's arm32 `mach_vm_*` are `uint64_t` unless `__IPHONE_OS_VERSION_MIN_REQUIRED < __IPHONE_5_0` (4570 `vm_types.h:127-135`); D13 pinned the pre-iOS-5 types unconditionally (`vm_types.h:104-109`) - that pin is why the wire gate exists.
- `kern_descrip.c`: 4570's limit is 40 MiB (`:1870`), no per-name gate; D13's 1280 KiB is the outlier the gate repairs. Stack, for the coupling below: 4570 `USRSTACK 0x27E00000` (4570 `bsd/arm/vmparam.h:10`) vs D13 `status.c:59`, gated `:67`.

## 3. iOS 7 dyld expectations vs the tree's constants

- Fixed VA from the artifact itself: `0x2c000000`, `0x38268000`, `0x39f48000`; region top `0x40000000`; dyld base `0x2be00000` (header +0x20).
- The tree's ARM constants do not encode it: `SHARED_REGION_BASE_ARM 0x30000000` / `SHARED_REGION_SIZE_ARM 0x10000000` / `NESTING_*` (`osfmk/mach/shared_region.h:67-70`). Only the gate's literals (`vm_shared_region.c:633-634`) and the wire bound literal `0x40000000` (`vm_unix.c:1191`) do.
- `VM_MAX_ADDRESS`: today `0x80000000` (`osfmk/mach/arm/vm_param.h:68`; CANCRO takes the `#else` of the `:63` board gate); gated `0x40000000`. The cache's span fits either way.
- `shared_region.h:71-72` (`SHARED_REGION_NESTING_MIN/MAX_ARM`) are literally `?` - unchecked edges if a rung ever needs them.

## 4. Risks

- **Entry window vs the 301.3 MiB cache.** Window `0x1e400000` = 484 MiB (`scripts/press_991.sh:31-34`), D13's `gMemSize` at `MANAGED_BASE 0xC0000000`; binding ceiling `RAM_CONSOLE_BASE (0xde500000) - MANAGED_BASE = 0x1e500000`, refused at `>=` ("use at most 0x1e400000", `src/entry/build_entry.sh:29626-29653`; separate 1 GiB L1-wrap refusal `:29618-29625`; default `0x04000000` `:29572/:1564`). Fully paged in, the cache leaves ~183 MiB. No VA interaction (window = kernel/identity RAM; cache = user VA).
- **VA collision when the gate turns on.** Today's stack top `0x2FE00000` (`status.c:59`; 991 `sp 0x2fdb0870`) sits inside cache map[0] `[0x2c000000, 0x38266000)`; the gated mode moves it to `0x2BE00000` (`:67`) = dyld's base, with dyld's image above it inside `[0x2be00000, 0x2c000000)`. The constants interlock (stack top == dyld base < region base); G1 without the stack gate maps the cache under a live stack.
- **Half-on.** Each gate is `#if IOS7_COMPAT_PLATFORM` **and** runtime `ios7_compat_vmabi_enabled()` (`osfmk/arm/ios7_compat.h:11-21` returns 0 for CANCRO) - opening the macro alone still runs the `#else` behavior; a new STAGE90 escape must open both halves.
- **Ordering.** G1 alone still fails the map call unless G3 is also on (wire `copyin` `:1581` precedes `_shared_region_map` `:1586`); G2's flag is exercised afterwards by libsystem's remap path; G4 matters only when the cache's signature is read. `vm_unix.c:1085-1097` documents dyld's mmap() fallback for a mismatched region.

## 5. Proposal - the first gate and its checker

If the post-992 press shows the next wall here, open **`vm_shared_region.c:626-638` first**: the tree's only carrier of the cache's own base, upstream of every other path, and checkable entirely by value. Checker `tools/check_ios7_shared_region.py` (style of `tools/check_commpage_alias.py`: objdump by value, `FAIL`/`ok` lines, exit 0/1/2, rehearsal against the previous image):
